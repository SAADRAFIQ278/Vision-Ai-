Getting Started with VisionAI

Welcome to VisionAI! This guide will help you get started with our AI video generation platform. Whether you're a content creator, marketer, or developer, VisionAI makes it easy to create stunning videos with artificial intelligence.

What is VisionAI?

VisionAI is a cutting-edge AI video generation platform that turns text prompts into professional-quality videos. Our advanced AI models understand your creative vision and generate cinematic videos with realistic motion, lighting, and style.

// Example: Generate a video with VisionAI
const visionAI = new VisionAI({ apiKey: 'your-api-key' });

const video = await visionAI.generate({
  prompt: 'A futuristic city with flying cars, cyberpunk style, 4k',
  model: 'visionai-pro',
  duration: 30,
  resolution: '4k'
});

VisionAI offers three AI models: VisionAI-Pro for cinematic quality, VisionAI-Studio for balanced performance, and VisionAI-Lite for fast prototyping.

Quick Start Guide

Follow these steps to create your first AI video with VisionAI:

Step 4: Generate & Export

Click "Generate" and watch as VisionAI creates your video. Once complete, you can preview, edit, or export your video in your preferred format and resolution.

Video Generation

Understanding the video generation process helps you get the best results from VisionAI.

Prompt Engineering

The quality of your generated video depends significantly on your prompt. Here are some tips for writing effective prompts:

  • Be specific: Describe the scene, style, mood, and key elements
  • Include style cues: Mention cinematic styles, artists, or genres
  • Define the setting: Location, time of day, weather, etc.
  • Specify quality: Use keywords like "4k," "high quality," "cinematic"
  • Describe motion: How objects move, camera angles, etc.
// Good prompt examples:
"A cinematic drone shot over a misty mountain range at sunrise, dramatic lighting, 8k"
"A professional product reveal with sleek dark background, smooth rotating animation, studio lighting"

Generation Settings

You can control various aspects of the generation process:

  • Duration: Video length in seconds (10-120)
  • Resolution: 720p, 1080p, 4K, or 8K (model dependent)
  • Style: Artistic style or visual theme
  • Seed: For reproducible results
  • Guidance Scale: How closely to follow the prompt

API Reference

The VisionAI API allows you to integrate AI video generation into your own applications. Here's a quick overview of the main endpoints.

Authentication

All API requests require an API key. Include it in the Authorization header: Authorization: Bearer YOUR_API_KEY

Generate Video

// POST /v1/generate
{
  "prompt": "A futuristic city with flying cars",
  "model": "visionai-pro",
  "duration": 30,
  "resolution": "4k",
  "style": "cyberpunk"
}

Get Status

// GET /v1/generation/{id}
{
  "id": "gen_abc123",
  "status": "processing|completed|failed",
  "progress": 75,
  "url": "https://visionai.com/videos/abc123.mp4"
}

List Models

// GET /v1/models
{
  "models": [
    { "id": "visionai-pro", "name": "VisionAI Pro", "max_resolution": "8k" },
    { "id": "visionai-studio", "name": "VisionAI Studio", "max_resolution": "4k" },
    { "id": "visionai-lite", "name": "VisionAI Lite", "max_resolution": "1080p" }
  ]
}

Authentication

VisionAI uses API keys for authentication. You can generate and manage your API keys from your dashboard.

API Key Management

  • Generate Key: Create a new API key from your dashboard
  • Revoke Key: Immediately revoke a compromised key
  • Key Permissions: Restrict keys to specific operations
  • IP Whitelist: Restrict API access to specific IP addresses
// Example: Using API key in a request
fetch('https://api.visionai.com/v1/generate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ prompt: '...' })
});

Webhooks

Configure webhooks to receive real-time notifications about video generation events.

Available Events

  • generation.started: When a generation begins
  • generation.progress: Progress updates during generation
  • generation.completed: When generation is complete
  • generation.failed: When generation fails

Webhook Payload

{
  "event": "generation.completed",
  "timestamp": "2026-01-15T10:30:00Z",
  "data": {
    "id": "gen_abc123",
    "url": "https://visionai.com/videos/abc123.mp4",
    "duration": 30,
    "resolution": "4k"
  }
}

Troubleshooting

Common issues and their solutions when using VisionAI.

Generation Fails

  • Check prompt: Ensure your prompt is clear and not too long
  • Check model limits: Some models have resolution or duration limits
  • Check API key: Verify your API key is valid
  • Check credits: Ensure you have enough generation credits

Poor Quality Output

  • Improve prompt: Use more descriptive language
  • Try a different model: Use a higher-quality model
  • Add style cues: Include "cinematic," "4k," "high quality"
  • Adjust settings: Increase guidance scale or change seed

API Rate Limits

  • Starter: 50 requests per day
  • Pro: 500 requests per day
  • Enterprise: Unlimited requests
